# SQL Скрипты и миграции базы данных Al-Warda

В этой папке собраны SQL-скрипты для инициализации структуры, миграций и обслуживания базы данных:

- **`supabase_schema.sql`** — Базовая схема базы данных каталога (таблицы `stocks`, `categories`, индексы, триггеры).
- **`supabase_product_image_queue.sql`** — Хранимая функция и структуры для атомарной работы очереди обработки изображений.
- **`conditional_image_delete.sql`** — Функция условного удаления изображений с защитой от одновременных изменений (`update_stock_image_if_unchanged`).
- **`proposal_catalog_columns.sql`** — Расширения схемы для поддержки расширенных атрибутов парфюмерии (ноты, объем, тип).
- **`al_warda_import.sql`** — Резервный дамп каталога парфюмерии.
